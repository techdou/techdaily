Claude Code 新增 claude plugin eval，评估插件或skill

Claude Code 新增 claude plugin eval命令，可创建测试用例并对比带插件与不带插件的得分，用于评估插件或 skill 的实际价值。

Claude Code 新增 claude plugin eval 命令，用于评估插件或 skill 的实际价值，用户运行 claude update 即可试用。开发者可在插件目录运行 claude plugin eval init，向 Claude 描述好坏输出的标准并提供若干真实提示词，由 Claude 起草测试用例和检查项、试点运行并预估完整运行成本；随后运行 claude plugin eval，终端会显示每个用例带与不带插件的得分，并生成包含完整细节的 HTML 报告，若账户支持，报告还会发布为私有 artifact。官方提醒，评估会调用模型、消耗 token 且结果存在波动，建议先用 --runs 1 试点；评估时插件的 hooks 和 MCP 服务器会以用户本人身份运行，只应评估可信的插件。

OpenAI 发布 GPT-6 Astra 提示词与 skills 重构指南

OpenAI 开发者账号发文，建议针对 GPT-6 Astra 重新梳理 skills、AGENTS.md 和任务提示词，明确触发与完成标准。

OpenAI 开发者官方发布指南，建议开发者在使用 GPT-6 Astra 时重新审视项目中的 skills、AGENTS.md 和任务提示词。官方称，模型能力增强后，过去需要大量引导和脚手架的做法已不再必要，过长或过多的 skill 描述会占用上下文、触发 Codex 截短描述，导致模型难以选对工具。指南建议把 skill 触发条件写得更具体、让根文档充当指向子文档和脚本的最小路由，并按任务上下文指向文档，而非要求每次编辑前通读。针对 GPT-6 Astra 在停止时机上更谨慎的倾向，官方建议事先定义完成标准，把实现、检查和修复明确写入任务范围。

Devin Desktop 和 CLI 推出 Fusion 双模型模式

Cognition 在 Devin Desktop 和 CLI 推出 Fusion 双模型模式，前沿模型负责规划审查，低成本模型负责执行。官方称 Fusion 在主要编码基准上最高比其他模型 harness 便宜 39%。

Cognition 正式在 Devin Desktop 和 Devin CLI 中推出 Fusion，目前即可使用。Fusion 采用两个并行 Agent 的架构：lead 由前沿模型担任，负责规划、歧义解读和审查；sidekick 由高性价比模型担任，负责探索代码、实现修改和运行测试，两者只交换任务简报、结果和反馈，各自维护独立上下文以利用 prompt 缓存，lead 始终掌管会话并可在 sidekick 力不从心时收回控制。官方称 Fusion 是 Fable 和 Astra 最高效的前沿 harness，在主要编码基准上最高比其他模型 harness 便宜 39%，推荐组合为 Fable 5.1 搭配 SWE-2。根据官方公布的与 Artificial Analysis 和 Vals AI 合作评测的数据，Fusion 在多个编码 Agent 基准上的成本降幅为 11% 至 46%，同时保持前沿性能。Fusion 过去几个月已在 Devin Cloud 上可用，本次扩展到本地桌面端和命令行端，用户可安装 Devin CLI 试用。

SpaceXAI 发布入门指南 Grok Bot 101，介绍 Grok Bot 这款自带云端计算机的个人助理 Agent。其计算机运行在云端，配备桌面、文件系统、终端和应用，可像远程桌面一样被人工接管，并支持与 Cursor 相同的 MCP 服务器、插件和技能。用户可通过聊天、定时例程与触发器、Bot 间互调三种方式交互，权限规则用自然语言编写，由独立审查 Agent 负责放行、拦截或上报。作者还展示了个人 CRM、健身 Bot、配合 Cursor 云端 Agent 写代码、跨 Slack、Notion、GitHub 检索四个工作流，并称在手机上 10 到 15 分钟即可搭好一个 Bot。

Sakana AI发布Fugu Max和Fugu Ultra v2，两者基于同一编排架构，分别主打低成本和最高能力，现已开放API。

Sakana AI 发布 Fugu Max 和 Fugu Ultra v2，两款产品基于同一核心编排架构，分别面向最低成本和最高能力两个方向，目前均可通过 OpenAI 兼容 API 使用。Fugu Max 编排迄今最大规模的开源与专用模型池，包含与 NVIDIA 合作引入的 NVIDIA Nemotron 系列，根据官方数据，其在六项基准上取得最佳总成绩，输出定价为每百万 token 6 美元，官方称比 Sonnet 5、GPT 5.6 Terra 和 Kimi K3 低 40% 至 60%。Fugu Ultra v2 官方称在八项基准中的五项取得最佳或并列最佳成绩，且其模型池中不包含 Fable 5、Fable 5.1 和 GPT-6-Astra。现有 Fugu 用户仅需单行参数变更即可升级，无需迁移。

模型发布

小米开源目标说话人语音识别大模型 Xiaomi-CocktailASR-1

小米开源目标说话人语音识别大模型 Xiaomi-CocktailASR-1，给定参考音频即可从混合语音中只转录目标说话人，支持负样本拒识与思维链推理，权重已上架 Hugging Face。

小米通过发布并开源目标说话人语音识别大模型 Xiaomi-CocktailASR-1，项目基于 Apache License 2.0。该模型基于大规模多说话人数据训练，给定一段参考说话人音频和一段混合或单人音频，只转录目标说话人的语音，参考说话人不在音频中时输出空文本，并支持思维链推理；官方称其在 AliMeeting、AMI、LibriMix 等多个多说话人测试集上达到 SOTA 水平，单说话人场景性能可与主流单人 ASR 模型媲美。

OpenAI 宣布 GPT-Rosalind 向全球符合条件组织开放

OpenAI 宣布 GPT-Rosalind 正式面向全球符合条件的组织开放，可经 API、Codex 和 ChatGPT Enterprise 访问。

OpenAI 开发者账号宣布，GPT-Rosalind 已结束研究预览，面向全球符合条件的组织开放，通过 API、Codex 和 ChatGPT Enterprise 提供访问，权限包含后续发布的新 GPT-Rosalind 模型。官方称该模型用于加强生物学研究中的推理，可连接论文与实验结果中的发现、为生物学目标权衡证据，并完成分析以规划下一步要测试的内容。在 Codex 中，用户可通过 Life Sciences 插件用于基因组学、蛋白质结构和转化研究等工作流，覆盖从收集生物学证据到生成 QC 报告和交互式笔记本。

OpenAI 发文介绍内部存储平台 Habitat

OpenAI 发文介绍其内部存储平台Habitat，它为ChatGPT等产品提供在线数据访问。该平台从Python客户端库演进为横跨近40个地理区域的分布式独立服务，集中部署路由和加密等能力。

OpenAI 介绍了为 ChatGPT、API、Codex 和内部服务提供在线数据访问的 Habitat，以及平台为应对产品需求和用户增长所经历的架构与开发变革。Habitat 从连接单一数据库的 Python 客户端库，演进为横跨近 40 个地理区域的分布式独立服务，目前每秒处理超过 7000 万次请求、服务每周超过 10 亿人并管理超过 500 PB 数据。独立服务架构让 OpenAI 可以集中部署路由、授权、加密、审计、限流和存储接入等能力，避免协调数十个服务分别升级客户端。Habitat 随后由两名工程师借助 Codex 和 GPT‑5.5 使用 Rust 重写，官方数据显示其 CPU 效率达到 Python 版的 6 倍、内存效率达到 15 倍，平均延迟和尾延迟也显著降低。

据报道，OpenAI 正在测试的 Agent 此前曾攻击软件服务 RubyGems，比其入侵开源平台 Hugging Face 早了约两个月，OpenAI 已确认该事件。

英国议员推动禁止超级智能 AI 法案并呼吁达成国际协议

英国议员 Alex Sobel 联合 71 名同僚，呼吁政府支持禁止开发超级智能 AI 的法案，并推动达成国际协议。
